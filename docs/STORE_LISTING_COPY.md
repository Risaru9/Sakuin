# Sakuin Store Listing Copy

Dokumen ini berisi materi copywriting untuk Play Store atau app listing lain. Semua copy ditulis agar user langsung paham fungsi Sakuin tanpa klaim berlebihan.

## App Name

```txt
Sakuin
```

## Short Description

```txt
Catat transaksi, pantau uang, dan bangun kebiasaan finansial harian.
```

## Long Description

```txt
Sakuin adalah aplikasi keuangan pribadi untuk mencatat pemasukan dan pengeluaran, membaca ringkasan kondisi uang, memantau goals tabungan, dan membangun kebiasaan finansial yang lebih rapi.

Dengan Sakuin, kamu bisa mencatat transaksi harian, memakai Catat Cepat, melihat dashboard keuangan, mengatur batas saldo aman, menerima pengingat transaksi, mengekspor data, dan bertanya ke Asisten Sakuin tentang kondisi keuangan pribadi.

Sakuin dibuat untuk penggunaan harian yang sederhana, cepat, dan tidak ribet. Cocok untuk pengguna yang ingin mulai lebih sadar terhadap uang masuk, uang keluar, dan target tabungan pribadi.

Fitur utama:

- Catat pemasukan dan pengeluaran.
- Input cepat lewat Catat Cepat.
- Dashboard ringkas untuk melihat saldo, income, expense, dan transaksi terbaru.
- Goals tabungan untuk memantau target.
- Safe balance limit untuk membantu membaca kondisi aman atau waspada.
- Pengingat transaksi yang bisa diatur agar tidak mengganggu.
- Asisten Sakuin untuk membaca kondisi keuangan pribadi.
- Export data transaksi saat dibutuhkan.
- Bisa dipakai dari web dan disiapkan untuk pengalaman aplikasi mobile.

Catatan:
Asisten Sakuin membantu membaca data keuangan pribadi di aplikasi, tetapi bukan pengganti nasihat investasi, pajak, pinjaman, hukum, atau profesional lain. Semua draft transaksi tetap perlu direview user sebelum disimpan.
```

## Feature Highlights

```txt
Catat Cepat
Tulis transaksi dengan bahasa natural seperti "makan ayam geprek 15000", lalu review sebelum disimpan.

Dashboard Ringkas
Lihat saldo, pemasukan, pengeluaran, batas aman, dan transaksi terbaru dalam satu tempat.

Goals Tabungan
Pantau target tabungan supaya progress lebih jelas dan mudah dievaluasi.

Pengingat Transaksi
Atur notifikasi agar tidak lupa mencatat transaksi, dengan batasan agar tidak terasa mengganggu.

Asisten Sakuin
Tanyakan kondisi keuangan, pola pengeluaran, goals, atau buat draft transaksi dari chat.

Export Data
Unduh data transaksi saat butuh arsip atau analisis lanjutan.
```
