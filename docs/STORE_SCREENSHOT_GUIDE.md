# Sakuin Store Screenshot Guide

Dokumen ini menjelaskan screenshot apa saja yang perlu disiapkan untuk Play Store dan bagaimana cara menjaganya tetap aman, jelas, dan konsisten.

## Tujuan Screenshot

Screenshot harus menjawab pertanyaan user:

```txt
Sakuin ini untuk apa?
Apa yang bisa saya lakukan?
Apakah tampilannya mudah dipakai di HP?
Apakah saya bisa mencatat transaksi dengan cepat?
Apakah app ini membantu saya memahami uang pribadi?
```

## Prinsip Visual

```txt
Gunakan data dummy.
Jangan gunakan email pribadi asli.
Jangan gunakan data finansial asli.
Pastikan warna putih, kuning, dan hitam konsisten.
Teks harus terbaca di layar kecil.
Jangan terlalu banyak annotation.
Jangan menampilkan halaman yang terlihat kosong.
```

## Screenshot Set Minimum

### 1. Dashboard

Tujuan:

Menunjukkan value utama Sakuin: ringkasan uang harian.

Yang harus terlihat:

```txt
Saldo aktif
Income bulan ini
Expense bulan ini
Review harian 30 detik
Status aman/waspada
```

Caption:

```txt
Ringkasan uang harian yang mudah dibaca.
```

### 2. Catat Cepat

Tujuan:

Menunjukkan bahwa transaksi bisa dicatat cepat tanpa spreadsheet.

Yang harus terlihat:

```txt
Input natural language
Draft transaksi
Review sebelum simpan
```

Caption:

```txt
Catat transaksi cepat dengan bahasa sederhana.
```

### 3. Transactions

Tujuan:

Menunjukkan daftar transaksi rapi dan mudah dipindai.

Yang harus terlihat:

```txt
List transaksi
Nominal
Kategori
Tanggal
Filter/search jika rapi
```

Caption:

```txt
Lihat pemasukan dan pengeluaran dalam satu tempat.
```

### 4. Goals

Tujuan:

Menunjukkan Sakuin bukan hanya catatan, tetapi juga membantu target.

Yang harus terlihat:

```txt
Goal aktif
Progress
Target amount
Sisa target
```

Caption:

```txt
Pantau progress tabungan dengan jelas.
```

### 5. AI Assistant

Tujuan:

Menunjukkan fitur unggulan Sakuin sebagai personal finance assistant.

Yang harus terlihat:

```txt
Full chat room mobile
Prompt user
Jawaban assistant
Saran prompt
```

Caption:

```txt
Tanya kondisi uangmu lewat Asisten Sakuin.
```

### 6. Reminder Settings

Tujuan:

Menunjukkan reminder bisa diatur dan tidak mengganggu.

Yang harus terlihat:

```txt
Status notifikasi
Frekuensi
Maksimal per hari
Quiet hours
Tombol tes
```

Caption:

```txt
Atur pengingat agar tidak lupa mencatat.
```

### 7. Export

Tujuan:

Menunjukkan user tetap punya kontrol atas data.

Yang harus terlihat:

```txt
Format export
Filter periode
Download action
```

Caption:

```txt
Export data saat kamu butuh laporan.
```

## Dummy Data yang Disarankan

Gunakan contoh data yang realistis tetapi tidak terlalu sensitif:

```txt
Nama: Rizal Mahardika atau User Sakuin
Email: user@sakuin.app
Saldo: Rp 2.960.000
Income: Rp 5.000.000
Expense: Rp 2.040.000
Kategori: Makanan, Transport, Hiburan, Tabungan, Gaji
Goals: Dana Darurat, Laptop, Liburan
```

## Checklist Sebelum Screenshot

```txt
[ ] Browser/device viewport mobile
[ ] Tidak ada data pribadi asli
[ ] Tidak ada email pribadi asli
[ ] Tidak ada error toast
[ ] Tidak ada loading state
[ ] Tidak ada empty state kecuali disengaja
[ ] Notifikasi/popup tidak menutup UI utama
[ ] AI Assistant tidak tertutup bottom nav
[ ] Teks tidak kepotong
[ ] Warna konsisten
```

## Catatan App Store

Untuk Play Store, screenshot sebaiknya dibuat dari device/viewport yang konsisten. Jangan mencampur terlalu banyak ukuran atau style mockup agar brand terlihat rapi.

Jika nanti ingin membuat screenshot yang lebih polished, gunakan frame device dan caption overlay yang tetap singkat.
